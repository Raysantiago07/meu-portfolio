✨ Sobre o projeto

Este projeto consiste no desenvolvimento do meu portfólio pessoal, criado para reunir e apresentar minhas experiências e aprendizados ao longo da minha formação em tecnologia.

Sou estudante do curso de Ciência da Computação na Universidade Federal do Ceará (UFC) e técnico em Desenvolvimento de Sistemas.

O portfólio foi pensado para apresentar minhas habilidades, meus projetos acadêmicos e pessoais e minha evolução na área de desenvolvimento de software.

🎯 Objetivos

Apresentar minha trajetória acadêmica e profissional.

Organizar meus principais projetos em um único lugar.

Compartilhar meus conhecimentos e tecnologias estudadas.

Facilitar o acesso ao meu GitHub e aos meus canais de contato.

Construir minha presença profissional na área de tecnologia.

🚀 Funcionalidades

Apresentação pessoal: informações sobre minha formação e meus interesses.

Habilidades técnicas: tecnologias e ferramentas com as quais tive contato.

Projetos: seleção de trabalhos desenvolvidos durante minha formação.

Formação e experiência: apresentação da minha trajetória acadêmica e experiência de estágio.

Contato: links para acessar meus perfis profissionais.

Layout responsivo: adaptação da interface a diferentes tamanhos de tela.
